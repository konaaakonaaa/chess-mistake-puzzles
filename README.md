# ♟️ Chess Mistake Puzzles

![python](https://img.shields.io/badge/python-3.9%2B-blue)
![license](https://img.shields.io/badge/license-MIT-green)

Программа превращает **твои собственные ошибки** в персональные шахматные задачи.

Она загружает твои партии с [Lichess](https://lichess.org), находит ходы, на которых ты терял партию (Stockfish), и делает из этих позиций тренажёр: «найди ход, который ты пропустил». Задачи повторяются по системе интервального повторения, как карточки Anki: решил с первого раза, и позиция вернётся позже, ошибся, и она будет возвращаться чаще.

## Возможности

- 📥 **Загрузка партий** по нику через публичное API Lichess (фильтр по режиму)
- 🔍 **Поиск ошибок Stockfish'ем:** считается падение шансов на победу, отбираются только позиции с одним ясным решением
- 🧩 **Терминальный тренажёр:** доска в консоли, ввод хода как `Nf3` или `g1f3`, подсказки, разбор после ответа
- 🔁 **Интервальное повторение:** 7 коробок, интервалы от 0 до 60 дней
- 📊 **Отчёт о слабостях:** в какой фазе партии, в каких дебютах и каким цветом ты ошибаешься чаще, сколько матов пропустил
- 📤 **Экспорт в PGN:** задачи с вариантами «лучший ход» и «как сыграл ты» можно импортировать в исследование Lichess
- 🗄️ Всё хранится локально в SQLite, повторный запуск не качает и не считает одно и то же дважды

## Установка

Нужны Python 3.9+ и движок **Stockfish**.

```bash
git clone https://github.com/konaaakonaaa/chess-mistake-puzzles.git
cd chess-mistake-puzzles
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

**Stockfish:** скачай с https://stockfishchess.org/download/ и распакуй.
- Linux: `sudo apt install stockfish`, macOS: `brew install stockfish`. Программа найдёт его сама.
- Windows: укажи путь к `.exe` через `--engine` или переменную окружения `STOCKFISH_PATH`.

## Быстрый старт

```bash
# 1. Загрузить последние 100 партий
python -m mistake_puzzles fetch ТВОЙ_НИК -n 100

# 2. Найти ошибки (20 партий за запуск, глубина 14)
python -m mistake_puzzles analyze ТВОЙ_НИК --engine "C:\stockfish\stockfish.exe"

# 3. Тренироваться
python -m mistake_puzzles train ТВОЙ_НИК

# 4. Посмотреть слабые места
python -m mistake_puzzles stats ТВОЙ_НИК
```

Если установить пакет (`pip install -e .`), вместо `python -m mistake_puzzles` можно писать `mistake-puzzles`.

## Команды

| Команда | Что делает | Полезные параметры |
|---|---|---|
| `fetch НИК` | Загружает партии в базу | `-n` число партий, `--perf blitz`, `--token` |
| `analyze НИК` | Анализ Stockfish'ем, создаёт задачи | `--engine`, `--depth 14`, `--max-games 20`, `--min-loss 20`, `--threads 2` |
| `train НИК` | Тренировка | `--limit 10`, `--category blunder`, `--phase endgame` |
| `stats НИК` | Отчёт о слабостях | |
| `export НИК` | Задачи в PGN | `-o puzzles.pgn`, `--category blunder` |

Общий параметр `--db путь` (ставится перед командой) меняет файл базы, по умолчанию `data/puzzles.db`.

В тренировке доступны команды: `hint` (первая подсказка называет фигуру, вторая поле), `show` (показать ответ), `quit` (выход). На задачу даётся 3 попытки.

## Как это работает

1. **Оценка позиций.** Stockfish оценивает каждую позицию партии (2 лучшие линии). Оценки переводятся в вероятность выигрыша по формуле Lichess: `win% = 50 + 50 · (2 / (1 + e^(−0.00368208 · cp)) − 1)`.
2. **Что считается ошибкой.** Ход игрока попадает в задачи, если одновременно:
   - он отличается от лучшего хода движка и снижает шансы на победу минимум на `--min-loss` процентных пунктов (по умолчанию 20: «ошибка», от 30: «зевок»);
   - позиция до хода ещё не была проигрышной (шансы не ниже 25%);
   - лучший ход заметно сильнее второго по силе (разница не меньше 10 п.п.), чтобы у задачи было одно решение;
   - ход сделан не в самом начале партии (пропускаются первые 6 полуходов).
3. **Теги и фазы.** Каждая задача получает фазу (дебют, миттельшпиль, эндшпиль) и, если нужно, тег `missed_mate` (пропущенный мат) или `allowed_mate` (ход, после которого тебе ставят мат).
4. **Повторение.** Метод коробок Лейтнера: с первой попытки → коробка +1; с подсказкой или со второй попытки → повтор через 1 день; не решил → коробка 0, и задача вернётся в этой же сессии. Интервалы: 0, 1, 3, 7, 14, 30, 60 дней.

## Ограничения

- Анализ при глубине 14 занимает порядка десятков секунд на партию, поэтому `analyze` по умолчанию берёт 20 партий за запуск. Для скорости увеличь `--threads` или уменьши `--depth`.
- Задача считается решённой только при совпадении с лучшим ходом движка. Равноценные альтернативы отсеиваются при создании задач (условие «одно решение»), но возможны редкие спорные случаи.
- Поддерживаются только стандартные шахматы, варианты (chess960, crazyhouse и т. д.) пропускаются.
- Без токена Lichess ограничивает частоту запросов, при ответе 429 программа ждёт минуту.
